2. Reflection Questions & Answers (One Sentence Each)

Q1: How many <rect> did you expect? How many did you get? Why?
We expected 142 <rect> elements (one per country), but got 1,704 <rect> elements because the raw dataset contains 12 survey years per country and was not filtered down to a single year.
Q2: How tall is one bar? Can you read the names?
Each bar is only about 2.2 pixels tall (y.bandwidth()), and the 142 country names are completely illegible because they overlap each other into a solid black smudge.
Q3: After your first fix, is the chart easy to read? What would you change?
After filtering data to 2007 (142 rows), the chart is still very cramped in a 500px window; to make it readable, we wrapped the SVG in a fixed-height scrollable container (max-height: 580px; overflow-y: auto) with an expanded SVG height (~3,500px) so each country receives ~22px height.
Q4: Now show the 10 richest countries. Is Norway in your chart? If not, what is missing?
Yes, Norway is first ($49,357) once the data is sorted descending by gdpPercap and sliced to the top 10 (.sort((a,b) => b.gdpPercap - a.gdpPercap).slice(0, 10)), which was missing in the raw comparison.
